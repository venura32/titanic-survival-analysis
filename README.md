#Titanic Survival Analysis

## Overview
Exploratory data analysis of Titanic passenger survival data using Python and pandas.

## Key Findings
- Overall survival rate : 38%
- Women survived at 74% vs men at 19%
- First class survival rate 63% was nearly 3x higher than third class 24%
- Average age of survivors (28) was slightly lower than non-survivors (30)

## Tools Used 
1. Python
2. pandas

## How to Run
1. Clone this repository
2. Run'python titanic_analysis.py'
